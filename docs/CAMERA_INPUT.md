# 本機鏡頭與手機網路攝影機

演出頁右側新增「鏡頭來源」與「選擇鏡頭」，六種演出模式皆可使用。

1. 使用設備內建或 USB 攝影機時，選「本機鏡頭」，再選裝置。
2. 使用手機時，先在手機與電腦的 DroidCam／Camo 等軟體完成連線，再選「手機鏡頭（DroidCam／Camo）」。
3. 手機來源會優先挑選 DroidCam、Camo、Iriun、EpocCam、iVCam 等已註冊的裝置；可從清單切換，其他名稱也能手動選取。
4. 新插入裝置後按「重新偵測」。若手機尚未出現在清單，系統顯示提示，保留手動選取其他名稱的方式。

選取的本機與手機裝置會各自記住。切換時釋放原攝影機，重新校正辨識輸入，保留原演出與 Unity 場景。映射模式請重新維持自然姿勢約 1.5 秒。手機軟體的連線與可用性仍由 DroidCam／Camo 提供。

實作僅更新六個既有網頁／辨識檔案，沿用原 Docker 埠與啟動方式。`BrowserValidation.json` 使用實際 MediaStream 與模擬裝置名稱測試六種演出模式、鏡頭釋放、裝置記憶、未連接提示、手動選取、重連及權限重試；未連接實體手機驗證。`BackendValidation.json` 記錄既有演出測試及舊影格攔截測試。USB／Wi-Fi 連線設定請在已安裝的手機攝影機軟體中完成。
