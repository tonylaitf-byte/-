# 俠客與琴師的放鬆待機

俠客改為低位持刀，雙臂收低、手肘微彎，刀尖朝外下方；酒壺維持直立。琴師收低外張的手肘，左手托琴頸，右手自然停在琴面外側。兩角使用 4.8 秒的小幅呼吸循環，腳部與角色根節點不做位移。

單人手勢模式在兩段演出之間使用原生待機動畫，持續保留左右平移。開始動作時交回 Animator；轉場以固定時間計算，避免較長的呼吸循環拖慢起勢。雙人俠客使用同一個 Idle 素材，琴師使用 MusicIdle；琴師動作的中立起止姿勢同步重建，以銜接新的持琴姿勢。即時手部映射仍使用原本的控制範圍與校正姿勢。

修改保留既有動畫 GUID、骨架、人物模型、語音、字幕與背景音樂。Unity 的原生動作測試場景及琴師動作控制器繼續引用相同素材。

`Validation.json` 包含原生循環、刀刃離地、腳底位置、托琴穩定、右手距離、單人待機／舞劍銜接、左右平移與雙人十個動作的檢查。右手距離使用保守的琴面／琴頸包圍範圍取樣，並非所有服裝表面的完整碰撞保證。

`CurveContinuity.json` 直接檢查序列化的四元數，補足 Unity 對極小角度的四捨五入。`BrowserValidation.json` 記錄實際 WebGL 播放；使用模擬控制資料，不啟用實體攝影機。

`After.png`、`RelaxedIdle.gif` 為 Unity 補光預覽；`WebGL_DuetIdle.png` 為原舞台實際網頁畫面。原檔與更新前網頁存於 `Preparation.json` 所記錄的備份資料夾。
